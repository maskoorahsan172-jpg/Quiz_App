# 🧠 Web Development Quiz App

A lightweight, responsive web application designed to test foundational knowledge of Web Development (HTML, CSS, JavaScript).

### 👉 Launch Quiz App

✨ Features
Interactive UI: Clean layout with clear question cards and smooth answer selections.

Instant Scoring: Automatically evaluates submitted answers and calculates the final score.

Responsive Design: Optimized for mobile phones, tablets, and desktop screens.

Zero Dependencies: Pure vanilla implementation without heavy external libraries.

## 🛠️  Components & Tech Stack
HTML5: Structures the layout, quiz card container, and question/option elements.

CSS3: Custom styles, colors, button hover states, and responsive flexbox design.

JavaScript (ES6):

Dynamic question rendering from array data.

DOM manipulation for interactive UI state changes.

Score tracking and final result screen logic.
